# Firebase

> Firebase is Google's app development platform — a backend-as-a-service suite for building, running, and growing web and mobile apps. It provides managed backend products (Authentication, Cloud Firestore, Realtime Database, Cloud Storage, Cloud Functions, Hosting, Cloud Messaging, Remote Config, Crashlytics, and more), Google-hosted REST APIs, first-party client and Admin SDKs, a cross-platform CLI, a local Emulator Suite, and an official MCP server.

## APIs

- [Firebase Management API](https://firebase.google.com/docs/projects/api/reference/rest): Create and manage projects, apps, and configuration (https://firebase.googleapis.com).
- [Cloud Firestore REST API](https://firebase.google.com/docs/firestore/use-rest-api): Documents, queries, and indexes (https://firestore.googleapis.com).
- [Realtime Database REST API](https://firebase.google.com/docs/reference/rest/database): Read/write JSON data over HTTPS.
- [Cloud Messaging HTTP v1 API](https://firebase.google.com/docs/reference/fcm/rest): Send notification and data messages (https://fcm.googleapis.com).
